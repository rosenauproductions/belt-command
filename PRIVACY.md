# Belt Command privacy policy

Last updated: 2 November 2026. Belt Command is made by Rosenau Productions (rosenauproductions@gmail.com).

**Short version: Belt Command has no accounts, no ads, no analytics and no tracking. We don't collect or sell personal data.**

## What stays on your device
- Settings (sound, graphics), your best scores and the player name you type are saved on your device only
  (in the browser's local storage, or in a settings file next to the game).

## Online play
Online play is optional. When you host or join a game:
- Your player name and your game input are sent to the other players in that game, and theirs to you.
- To connect players, the game uses connection services run by others. They see your IP address, as any website does:
  - **Browser games (room codes and invite links):** the PeerJS connection server introduces the players, and if a direct link
    isn't possible the game data is relayed through PeerJS's relay (TURN) servers. Google's STUN servers help players find each other.
  - **Games hosted on a Batocera box over the internet:** traffic passes through a Cloudflare tunnel.
- We don't run servers that store your data, and no game data is kept after the game ends.

## Children
Belt Command doesn't knowingly collect personal information from anyone, including children under 13. Player names are free
text that only the other players in the same game see; we recommend not using your real name.

## Website
The website (belt-command.vercel.app) is hosted by Vercel, which keeps standard server logs (such as IP addresses) for security.
